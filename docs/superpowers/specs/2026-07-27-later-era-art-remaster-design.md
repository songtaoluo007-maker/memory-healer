# 拾忆 · 1990—2089 电影美术重制设计

> **状态：** 美术方向与生产范围已批准，等待书面规格复核。
>
> **范围：** 4 张年代主场景、6 张 NPC 立绘、4 张代表记忆碎片，共 14 张核心资产。

## 1. 目标

在不修改后端权威内容、剧情规则和存档契约的前提下，把 1990、2024、2050、
2089 四个年代升级到与 1972 纵向切片一致的电影品质，并建立可继续扩展其余碎片
美术的资产边界。

成功标准：

- 五个年代像同一部电影，而不是五套无关插画。
- 陈守义和小雨跨年龄仍可被识别为同一人物。
- 场景中的关键物件与权威热点位置相符。
- 桌面、平板和手机构图均保留人物、字幕、热点和选择的安全区。
- 代表碎片发现时获得独立的电影插片，而不只显示文字。
- 新主美术加载失败时，旧 SVG 仍能承载完整游戏流程。

## 2. 产品范围

采用“场景—人物—代表碎片”闭环，而不是一次性绘制全部 14 个后续碎片。

### 2.1 本轮包含

| 类别 | 数量 | 资产 |
| --- | ---: | --- |
| 主场景 | 4 | 1990 深圳火车站、2024 深圳城中村、2050 颁奖典礼、2089 拾忆实验室 |
| NPC 立绘 | 6 | 1990 陈守义、站台陌生人；2024 陈守义；2050 小雨、记者；2089 小雨投影 |
| 代表碎片 | 4 | 南下车票、小雨的信、水晶奖杯、最后一个皮影人偶 |

### 2.2 本轮不包含

- 不修改场景、NPC、热点、碎片或选择的 canonical ID。
- 不改写对话、结局条件或存档 schema。
- 不绘制其余十个后续碎片特写。
- 不在生成图片中放置需要准确阅读的招牌、证书、票据或品牌文字。
- 不在本轮加入新音乐、配音或运营分析事件。

## 3. 统一美术语言

- 基线：动画电影写实，保留真实材质和中国城市年代感。
- 母题：皮影幕、刻刀纹理、暖窗光和记忆颗粒贯穿五幕。
- 演进：1990—2050 以现实主义为主，2089 进入受控的超现实记忆重组。
- 镜头：主场景不出现清晰正面的可对话 NPC，人物由独立立绘叠加，避免重复角色。
- 文本：生成图片不承担准确文字；真实标题、年份、信件和证书内容由 Vue 渲染。
- 画面：禁止水印、Logo、乱码招牌、现代物件穿帮和无叙事用途的额外人物特写。

## 4. 四幕色彩脚本与构图

### 4.1 1990 · 深圳火车站

核心情绪是“离乡与机会”。绿皮火车和拥挤站台形成横向运动，煤烟灰、火车绿和
钨丝灯构成主色。上方保留圆形站台时钟；画面左中部容纳车票和信件热点，右侧旧
木箱对应皮影道具热点。人群作为环境层，不出现可与陈守义或陌生人混淆的清晰正脸。

人物：

- 陈守义，43 岁，延续 1972 立绘的骨相、眼神和手部特征；蓝灰工装更旧，怀抱
  皮影木箱，既犹豫又坚定。
- 站台陌生人，约 28 岁，新夹克、南下青年外观，热情但带观察感，不使用商业精英
  的现代造型。

代表碎片是被汗水浸皱的南下硬座票。图片只表现纸张、印章和年代质感，准确日期、
路线与价格由 UI 覆盖。

### 4.2 2024 · 深圳城中村

核心情绪是“遗忘与孤独”。使用更近、更压迫的室内镜头：旧工作台、刻刀、泛黄
剧照、空椅和未完成的皮影占据前景，窗外是雨夜蓝与被防盗网切割的深圳霓虹。信件
位于桌面右侧，剧照和最后演出海报位于左侧墙面，与热点位置一致。

人物：

- 陈守义，77 岁，保持 1972/1990 的同一骨相。头发花白、身体微驼、手握刻刀却
  迟迟没有落下；神情不是单纯悲伤，而是努力回忆。

代表碎片是被反复展开、折好的小雨来信。纸面可出现儿童笔迹感，但不生成可读句子；
真实信件内容由 UI 显示。

### 4.3 2050 · 北京颁奖典礼

核心情绪是“迟来的认可”。象牙白、典礼金和克制的数字红构成开阔舞台；中央奖杯、
左侧时光照片墙、右侧全息皮影台、下方观众暗部对应四个热点。大屏幕只呈现抽象
皮影轮廓和年代影像，不生成活动标题。

人物：

- 小雨，48 岁，成熟坚定、温柔有力量。现代正装融入细微皮影纹样，眼神带有讲到
  爷爷时的情绪波动。
- 记者，约 30 岁，专业、有人文关怀，服装和设备具有近未来感但不过度科幻。

代表碎片是折射暖金光晕的水晶奖杯。底座不生成准确奖项文字，真实名称由 UI 呈现。

### 4.4 2089 · 拾忆实验室

核心情绪是“记忆重组与传承”。深墨黑空间中，中央躺椅和神经接口形成现实锚点；
全息青、记忆紫光带把 1972 窗幕、1990 火车、2024 雨窗和 2050 奖杯重组为悬浮
记忆残片。全家福位于右侧、证书位于左侧、孙悟空皮影位于中部，与热点一致。

人物：

- 小雨以年轻大学生的记忆投影出现，和 2050 小雨保持同一骨相。人物边缘有轻微
  全息分解、扫描线和透明记忆碎屑，明确她不是 2089 的现实年龄状态。

代表碎片是最后一个孙悟空皮影人偶。金箍棒上的真实赠言不在图片中生成，由 UI
显示。

## 5. 角色连续性

### 5.1 陈守义

以现有 1972 陈守义立绘作为身份参考。1990 与 2024 立绘分别进行自然中年化和
老年化，必须保留：

- 眼距、眉骨、鼻梁和下颌的基本比例。
- 克制、专注的眼神。
- 皮影匠人的手部老茧和持物方式。
- 同一方向的电影侧光和近似的胸像/半身镜头。

### 5.2 小雨

先生成 2050 小雨的现实人物，再以其为身份参考生成 2089 年轻投影。两张立绘必须
保留眼睛、鼻梁、嘴角和脸型关系；年龄差与全息效果不能改变身份识别。

### 5.3 独立人物

站台陌生人与记者不复用其他角色骨相。二者的服装与道具只服务各自年代，不建立
额外剧情关系。

## 6. 资产清单与格式

运行时资产位于 `frontend/src/assets/cinematic/`：

```text
scene-1990-shenzhen-station.webp
scene-2024-urban-village-room.webp
scene-2050-award-ceremony.webp
scene-2089-memory-lab.webp

chen-shouyi-1990.webp
stranger-1990.webp
chen-shouyi-2024.webp
xiaoyu-2050.webp
journalist-2050.webp
xiaoyu-2089-projection.webp

fragment-1990-train-ticket.webp
fragment-2024-xiaoyu-letter.webp
fragment-2050-award-trophy.webp
fragment-2089-last-puppet.webp
```

生成源图使用内置 imagegen。场景采用宽幅构图并为 2.39:1 裁切预留安全区；人物
采用竖幅半身构图；碎片采用电影微距特写。最终运行时使用高质量 WebP，避免把
14 张 PNG 原图全部加入首包。

## 7. 前端架构

### 7.1 场景与人物注册表

扩展 `stage/presentation.ts`，仍只保存展示信息，不保存剧情规则。

`ScenePresentation` 从“单张 portrait + NPC ID 列表”升级为：

```ts
interface ScenePresentation {
  id: string
  eraLabel: string
  locationLabel: string
  palette: CinematicPalette
  background: string
  portraits: Readonly<Record<string, string>>
  alt: string
  composition: {
    desktopFocus: readonly [number, number]
    mobileFocus: readonly [number, number]
  }
}
```

`CinematicStage` 根据 `activeNpcId` 选择对应人物立绘。这样 1990 和 2050 的两个
NPC 不会错误共用同一张人物图。不存在的 NPC 映射返回空，不影响对话功能。

### 7.2 代表碎片注册表

新增纯展示映射 `getFragmentPresentation(fragmentId)`，只映射四个 canonical
fragment ID 到图片、替代文本和焦点位置。`Game` 的碎片弹层在存在图片时显示
电影插片；其余碎片继续使用现有无图布局。

映射关系：

- `train_ticket_fragment`
- `fragment_letter`
- `award_trophy_fragment`
- `fragment_last_puppet`

### 7.3 加载与降级

- Vite 只在模块中保存静态资源 URL；浏览器仅在当前场景或当前碎片出现时加载图片。
- `CinematicStage` 沿用当前 Pixi 加载失败回退：主场景失败时显示旧
  `SceneIllustration`。
- 人物或碎片图片失败时隐藏图片，保留角色信息、文本、关闭按钮和剧情操作。
- 不允许单个美术资源失败阻断探索、对话、选择、存档或结局。

## 8. 性能与响应式

- 背景目标单张不超过 1.5 MB，人物单张不超过 800 KB，碎片单张不超过 600 KB。
- 当前场景之外的图片不主动预加载。
- 桌面继续使用 2.39:1 舞台；人物位于右侧并横向渐隐。
- 手机主场景使用独立 `mobileFocus`，人物透明度降低并移到对白抽屉上方。
- 390×844 下热点、字幕、人物和因果选择不得重叠。
- `prefers-reduced-motion` 下图片只做即时显隐，不进行镜头推拉或全息抖动。

## 9. 错误处理与生产复核

每张生成图先检查主体、年代、构图、乱码、额外人物和身份连续性。单图不合格时只
针对一个问题迭代，不同时改变风格、镜头和主体。

重点拒收条件：

- 陈守义或小雨跨年代无法识别为同一人物。
- 图片含可见乱码、品牌、水印或错误年代物件。
- 场景关键热点物件缺失或落入 UI 遮挡区。
- 主场景内出现与独立 NPC 立绘重复的清晰角色。
- 手机裁切后只剩建筑或人物被裁掉。

## 10. 测试与验收

自动化：

- 更新 presentation registry 测试，确保五个场景均有电影注册项。
- 断言六个 NPC ID 均映射到不同且存在的立绘。
- 断言四个代表碎片有展示映射，其余碎片安全返回空。
- 保持前端 37 项现有测试、类型检查、Lint、格式和生产构建通过。
- 保持后端 168 项测试、内容校验、迁移检查和同域冒烟通过。

浏览器：

- 逐幕检查 1990、2024、2050、2089 的背景、热点、两类 NPC 对话和代表碎片。
- 覆盖 390×844、768×1024、1440×900、1920×1080。
- 阻断每幕主背景请求，确认旧 SVG 与完整操作仍存在。
- 阻断人物和碎片请求，确认文字与关闭/继续操作仍可用。
- 检查控制台、加载时闪烁、立绘切边、字幕遮挡和热点错位。
